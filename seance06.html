1. Accroche : Comment fonctionne la barre de recherche d'un site e-commerce ? 15 min — Oral

Notre base boutique_info est maintenant remplie. Lorsqu'un visiteur du site TechStore coche « Catégorie : Accessoire », saisit « Prix entre 50 et 200 DT » et clique sur « Trier par prix croissant », le site envoie en coulisses une requête SELECT au SGBDR.

Deux opérations fondamentales à distinguer :
  • La projection (verticale) : Choisir uniquement les colonnes à afficher (clause SELECT).
  • La sélection (horizontale) : Filtrer uniquement les lignes qui respectent une condition (clause WHERE).
Guide Enseignant — Traduction de l'IHM vers la requête SQL
  • Correspondance composant web ↔ Clause SQL :
    • Colonnes visibles (Nom, Prix, Image) : SELECT refProd, designation, prixUnit (Projection).
    • Filtre catégorie (« Accessoire ») : WHERE categorie = 'Accessoire' (Sélection).
    • Filtre intervalle de prix (50 à 200 DT) : AND prixUnit BETWEEN 50 AND 200.
    • Menu de tri (« Prix croissant ») : ORDER BY prixUnit ASC.
  • Requête SQL complète résultante : 
    SELECT refProd, designation, prixUnit
FROM Produit
WHERE categorie = 'Accessoire'
  AND prixUnit BETWEEN 50 AND 200
ORDER BY prixUnit ASC;
  • Bilan méthodologique : Toute recherche web sur base de données repose sur ce triptyque : QUOI afficher (SELECT), OÙ chercher (FROM) et QUELS critères (WHERE).

2. Synthèse : Structure et opérateurs d'une requête SELECT 25 min — Trace écrite

Figure 6.1 — Géométrie SQL : intersection de la projection verticale (SELECT) et de la sélection horizontale (WHERE).

A. Syntaxe générale et ordre strict des clauses

SELECT [DISTINCT] col1 [AS alias1], col2 ...
FROM NomTable
[WHERE condition]
[ORDER BY col_tri1 [ASC | DESC], col_tri2 [ASC | DESC]]
[LIMIT nombre];
  • * remplace la liste de toutes les colonnes de la table.
  • DISTINCT supprime les lignes en doublon dans le résultat affiché.
  • AS renomme temporairement une colonne à l'affichage (ex. : prixUnit AS Prix_DT).
  • ORDER BY trie par défaut par ordre croissant (ASC). Utilisez DESC pour l'ordre décroissant.
  • LIMIT n restreint le résultat aux n premières lignes (très utile avec ORDER BY pour un « Top 3 »).

B. Opérateurs utilisables dans la clause WHERE

Catégorie Opérateurs Exemple et signification
Comparaison =, <> (ou !=), <, <=, >, >= prixUnit <= 500 (prix inférieur ou égal à 500)
Logiques AND, OR, NOT ville = 'Sousse' AND tel IS NOT NULL
Attention : AND est prioritaire sur OR — utilisez des parenthèses (...) !
Intervalle BETWEEN v1 AND v2
NOT BETWEEN ...		 prixUnit BETWEEN 100 AND 500
Bornes incluses (équivalent à >= 100 AND <= 500). Fonctionne aussi sur les dates.
Liste de valeurs IN (v1, v2, ...)
NOT IN (...)		 ville IN ('Sousse', 'Tunis')
Plus court que ville = 'Sousse' OR ville = 'Tunis'.
Motif texte LIKE 'motif'
NOT LIKE 'motif'		 % = 0, 1 ou plusieurs caractères quelconques.
_ = exactement 1 seul caractère quelconque.
Ex. : 'PC%' (commence par PC), '%USB%' (contient USB), '____' (4 lettres exactes).
Valeur absente IS NULL
IS NOT NULL		 tel IS NULL (téléphone non renseigné).
Jamais tel = NULL !

3. TP guidé : 12 requêtes graduelles sur « boutique_info » 40 min — Sur machine

Rappel des tables interrogées aujourd'hui :

Client (#idClt, nom, prenom, ville, tel, dateInscr, email)
Produit (#refProd, designation, categorie, prixUnit, qteStock)

Dans phpMyAdmin (base boutique_info, onglet SQL), écrivez et testez les 12 requêtes suivantes en vérifiant à chaque fois le nombre de lignes obtenues :

  1. Affichage complet : Afficher toutes les colonnes de tous les produits.
  2. Projection et alias : Afficher la référence, la désignation (alias Article) et le prix unitaire (alias Prix_DT) de tous les produits.
  3. Doublons (DISTINCT) : Afficher la liste des villes (sans répétition) où résident les clients.
  4. Sélection simple : Afficher la référence et la désignation des produits en rupture de stock (qteStock = 0).
  5. Opérateur AND : Afficher les produits de la catégorie 'Accessoire' dont le stock est supérieur ou égal à 15.
  6. Intervalle (BETWEEN) : Afficher les produits dont le prix unitaire est compris entre 100 et 500 DT inclus.
  7. Liste (IN) : Afficher le nom, le prénom et la ville des clients habitant à 'Sousse', 'Tunis' ou 'Monastir'.
  8. Motif LIKE avec % : Afficher tous les produits dont la désignation commence par 'PC Portable'.
  9. Motif LIKE avec _ : Afficher le nom et le prénom des clients dont le prénom comporte exactement 4 caractères.
  10. Valeur absente (IS NULL) : Afficher les clients dont le numéro de téléphone n'est pas renseigné.
  11. Tri combiné (ORDER BY) : Afficher la catégorie, la désignation et le prix de tous les produits, triés par catégorie (ordre alphabétique A→Z) puis par prix décroissant.
  12. Palmarès (ORDER BY + LIMIT) : Afficher la désignation et le prix des 3 produits les plus chers de la boutique.
Corrigé — Les 12 requêtes SELECT sur boutique_info 
-- 1. Tous les produits (8 lignes)
SELECT * FROM Produit;

-- 2. Projection avec alias (8 lignes)
SELECT refProd, designation AS Article, prixUnit AS Prix_DT
FROM Produit;

-- 3. Villes distinctes des clients (4 lignes : Sousse, Tunis, Sfax, Monastir)
SELECT DISTINCT ville FROM Client;

-- 4. Produits en rupture de stock (1 ligne : P06)
SELECT refProd, designation
FROM Produit
WHERE qteStock = 0;

-- 5. Accessoires avec stock >= 15 (1 ligne : P03)
SELECT *
FROM Produit
WHERE categorie = 'Accessoire' AND qteStock >= 15;

-- 6. Prix entre 100 et 500 DT inclus (3 lignes : P04, P05, P07)
SELECT refProd, designation, prixUnit
FROM Produit
WHERE prixUnit BETWEEN 100 AND 500;

-- 7. Clients de Sousse, Tunis ou Monastir (5 lignes)
SELECT nom, prenom, ville
FROM Client
WHERE ville IN ('Sousse', 'Tunis', 'Monastir');

-- 8. Désignation commençant par 'PC Portable' (2 lignes : P01, P02)
SELECT *
FROM Produit
WHERE designation LIKE 'PC Portable%';

-- 9. Prénom d'exactement 4 caractères (3 lignes : Sami, Ines, Nour)
SELECT nom, prenom
FROM Client
WHERE prenom LIKE '____';

-- 10. Clients sans téléphone (1 ligne : Aya Mansouri)
SELECT idClt, nom, prenom
FROM Client
WHERE tel IS NULL;

-- 11. Tri par catégorie croissante puis prix décroissant (8 lignes)
SELECT categorie, designation, prixUnit
FROM Produit
ORDER BY categorie ASC, prixUnit DESC;

-- 12. Top 3 des produits les plus chers (P01: 2450, P02: 1890, P08: 520)
SELECT designation, prixUnit
FROM Produit
ORDER BY prixUnit DESC
LIMIT 3;

4. Atelier « Chasse aux pièges SELECT » 15 min

Piège 1 — Comparer avec NULL

-- L'élève cherche les clients qui n'ont pas de téléphone
SELECT nom, prenom FROM Client WHERE tel = NULL;

Question : Cette requête ne renvoie aucune erreur, mais retourne 0 ligne alors qu'Aya n'a pas de téléphone. Pourquoi ?

Corrigé — Piège 1 En SQL, NULL signifie « valeur inconnue » : on ne peut jamais la tester avec = ou <> (car NULL = NULL vaut Inconnu, pas Vrai). Il faut obligatoirement écrire WHERE tel IS NULL.

Piège 2 — Priorité entre AND et OR

-- L'élève veut les produits de catégorie 'Ordinateur' ou 'Périphérique' à moins de 500 DT
SELECT designation, categorie, prixUnit
FROM Produit
WHERE categorie = 'Ordinateur' OR categorie = 'Périphérique' AND prixUnit < 500;

Question : Pourquoi les PC portables à 2450 DT et 1890 DT apparaissent-ils quand même dans le résultat ? Corrigez la requête.

Corrigé — Piège 2 AND étant prioritaire sur OR, SQL lit : categorie = 'Ordinateur' OR (categorie = 'Périphérique' AND prixUnit < 500). Il faut entourer le OR de parenthèses :
WHERE (categorie = 'Ordinateur' OR categorie = 'Périphérique') AND prixUnit < 500
(Ou encore plus proprement : WHERE categorie IN ('Ordinateur', 'Périphérique') AND prixUnit < 500.)

Piège 3 — Ordre des clauses

SELECT designation, prixUnit
FROM Produit
ORDER BY prixUnit DESC
WHERE qteStock > 0;
Corrigé — Piège 3 Erreur de syntaxe : WHERE doit toujours être placé avant ORDER BY (ordre fixe : SELECT → FROM → WHERE → ORDER BY → LIMIT).

5. Application en autonomie : Requêtes sur « Client » et « Commande » 15 min

Écrivez sur feuille les 4 requêtes SQL correspondant aux demandes suivantes (sur Client et Commande(#numCmd, dateCmd, idClt#)) :

  1. Afficher les numéros et dates des commandes passées entre le 1er février 2026 et le 31 mars 2026 inclus, triées de la plus récente à la plus ancienne.
  2. Afficher le nom, le prénom et la ville des clients qui n'habitent ni à 'Tunis' ni à 'Sfax'.
  3. Afficher tous les produits dont la désignation contient le mot 'USB' ou 'SSD', et qui sont disponibles en stock (qteStock > 0).
  4. Afficher le nom, le prénom et la date d'inscription des 2 clients les plus anciens (premiers inscrits) disposant d'un numéro de téléphone.
Corrigé — Requêtes en autonomie 
-- 1. Commandes de février et mars 2026, de la plus récente à la plus ancienne
SELECT numCmd, dateCmd
FROM Commande
WHERE dateCmd BETWEEN '2026-02-01' AND '2026-03-31'
ORDER BY dateCmd DESC;

-- 2. Clients hors Tunis et Sfax
SELECT nom, prenom, ville
FROM Client
WHERE ville NOT IN ('Tunis', 'Sfax');

-- 3. Produits contenant USB ou SSD et en stock (attention aux parenthèses !)
SELECT *
FROM Produit
WHERE (designation LIKE '%USB%' OR designation LIKE '%SSD%')
  AND qteStock > 0;

-- 4. Les 2 clients les plus anciens ayant un téléphone
SELECT nom, prenom, dateInscr
FROM Client
WHERE tel IS NOT NULL
ORDER BY dateInscr ASC
LIMIT 2;

6. Quiz éclair de clôture 10 min

1. Joker LIKE : Quelle est la différence entre LIKE 'A%' et LIKE 'A_' ?
Réponse : 'A%' correspond à toute chaîne commençant par A (quelle que soit sa longueur : "A", "Aya", "Amine"), alors que 'A_' ne correspond qu'aux chaînes de 2 caractères exacts commençant par A (ex. "Al").
2. Bornes : Dans WHERE prixUnit BETWEEN 100 AND 500, un produit coûtant exactement 500 DT est-il affiché ?
Réponse : Oui — l'opérateur BETWEEN inclut toujours ses deux bornes (100 et 500).
3. Effet d'une requête : La clause ORDER BY prixUnit DESC modifie-t-elle physiquement l'ordre des lignes enregistrées dans la table Produit ?
Réponse : Non — une requête SELECT ne modifie jamais les données stockées ; elle trie uniquement le résultat affiché.
4. Raccourci : Comment réécrire plus proprement WHERE categorie = 'Ordinateur' OR categorie = 'Stockage' OR categorie = 'Accessoire' ?
Réponse : WHERE categorie IN ('Ordinateur', 'Stockage', 'Accessoire').
5. Alias : Si je veux donner un alias contenant un espace (ex. Prix Unitaire), que dois-je ajouter autour de l'alias ?
Réponse : Des apostrophes ou guillemets (ex. AS 'Prix Unitaire'), ou remplacer l'espace par un underscore (AS Prix_Unitaire).
